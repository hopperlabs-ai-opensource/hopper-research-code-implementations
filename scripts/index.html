FROM DEMO TO YOUR OWN PROBLEM

Take the smallest useful piece.

1. Name the decision

Which record matters? How should several examples contribute? What must be true before a report is returned?

2. Change one thing

Edit a fact, a feature, or a source record. Predict the result before looking. The trace shows where your prediction and the computation differ.

3. Start with a baseline

Compare with a dictionary lookup, a simple average, or a filter. Use the extra mechanism only when it helps your problem.

Clone once. Run locally.

git clone https://github.com/hopperlabs-ai-opensource/hopper-research-code-implementations.git
cd hopper-research-code-implementations
npm start

Requires Node.js 22+. Open the local address printed in your terminal. You can also open dist/index.html directly. Run npm run check for the tests and artifact build.

Original MIT-licensed educational implementations. The attention example is a small trained lookup, not a full Transformer. The workflow uses deterministic tools, not a live AI agent. The examples make no benchmark-reproduction claims.
